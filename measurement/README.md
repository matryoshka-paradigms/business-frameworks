# Measurement — with and without the skill

Method, questions, runner and results for the table in `OVERVIEW.md`. Window 2026-10-08; Claude Code headless; Haiku n = 20 per condition, Opus n = 8. `grade.py` needs the answer keys (`questions.json` with a `key` field), which are not published because they restate the paid node rules; the rubric is in the file. To reproduce the runs: `./run.sh haiku without`, `./run.sh haiku forced` (the plugin path in `PLUGIN_DIR`), then `python3 report.py`. The runner and the grader start the nested Claude Code with this shell's environment unchanged and an empty working directory; run them from a plain shell, not from inside a Claude Code session, so the nested session inherits no parent context, and it authenticates with the login stored under `HOME`. The 2026-10-08 runs were made from inside a cloud session, so their runner instead rebuilt the environment from a short list of variables (path, home, proxy and certificate settings and that container's own credentials); that is the one difference from the published scripts.
