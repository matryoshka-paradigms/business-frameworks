# Measurement — with and without the skill

Method, questions, runner and results for the table in `OVERVIEW.md`. Window 2026-10-08; Claude Code headless; Haiku n = 20 per condition, Opus n = 8. `grade.py` needs the answer keys (`questions.json` with a `key` field), which are not published because they restate the paid node rules; the rubric is in the file. To reproduce the runs: `./run.sh haiku without`, `./run.sh haiku forced` (the plugin path in `PLUGIN_DIR`), then `python3 report.py`. The runner and the grader pass the nested Claude Code only path, home, proxy and certificate variables, read by name, and forward no credential; the nested session uses the login stored under `HOME`. The 2026-10-08 runs were made in a cloud container whose runner also forwarded that container's own credential variables; that is the one difference from the published scripts.
